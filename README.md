
## 📌 About the Project

This is my personal portfolio website, created to showcase my skills, projects, education, and contact information in a professional and user-friendly way.

The website provides an overview of my technical skills and projects and serves as my online professional profile.

## 🚀 Features

* Responsive and modern portfolio design
* Home section with personal introduction
* About Me section
* Skills section
* Projects showcase
* Contact section
* Mobile-friendly layout
* Simple and clean user interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
Portfolio/
│
├── index.html

    └── images/
```

## 🎯 Project Objective

The main objective of this project is to create a professional online portfolio where I can showcase my technical skills, projects,and education,

This project also helped me improve my practical knowledge of HTML, CSS, JavaScript, responsive web design, and website development.

## 💡 What I Learned

Through this project, I learned:

* Creating web pages using HTML
* Designing responsive layouts using CSS
* Adding interactivity using JavaScript
* Creating navigation between different sections
* Organizing website files and assets
* Deploying and managing a project using GitHub
